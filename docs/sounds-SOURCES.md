# Sound sources (steam asset clearance)

Provenance for every wav in `frontend/static/sounds/`, traced through the upstream
[Monkeytype repository](https://github.com/monkeytypegame/monkeytype) history (cited only as the upstream source for provenance).

**Method.** A blobless clone of upstream was searched with `git log --diff-filter=A --follow`
for every file, through the renames `public/sound` → `static/sound` (2020-11) →
`frontend/static/sound` (2022-02, #2441) → `frontend/static/sounds/<pack>/<n>.wav` (2026-05, #7884),
with loudness normalization in #7515 (2026-02). For each adding commit we read the commit
message, the PR description and the PR review comments (GitHub API), and searched upstream
markdown/docs for credits. No upstream file lists sound credits or licences.

**Rule.** A file is TRACED only when its original author and licence are documented. Anything
else is UNTRACED. Nothing is inferred.

**Result.** 155 files: **2 TRACED**, **153 UNTRACED**. Update 2026-11-04: the 21 `click1`–`click5` files are now **GENERATED** by `scripts/generate-click-sounds.py` (see rows below).

| Licence | Files |
|---|---|
| GPL-3.0 (contributor-synthesized, contributed to upstream) | 2 (error2, error3) |
| UNTRACED | 153 |
| CC-BY / CC0 / other verified | 0 |

**CC-BY attribution.** No CC-BY sounds are present, so no attribution text is needed.

**Steam build.** All UNTRACED packs are excluded from the steam build
(`src/ts/constants/sound-clearance.ts`, `vite-plugins/steam-asset-clearance.ts`): files are
deleted from the build output, their options are hidden in settings and the command line,
playback is a no-op, and synced web configs that select them are reset to `off`. On steam
the click options left are click1–click5 (generated by `scripts/generate-click-sounds.py`, allowed on steam since 2026-11-04) and the synthesized ones (sine, sawtooth, square, triangle,
pentatonic, wholetone; generated in code, no files) and the error options left are triangle and
square. The time warning setting is hidden. The web build is unchanged.

**CC0 replacement candidates (not added; licence to be verified per file before use).**
- Kenney "Interface Sounds" / "UI Audio" packs (kenney.nl), published as CC0.
- Freesound.org items individually marked CC0 (filter by licence; check each file page).
- Original recordings or synthesis made in-house (simplest to clear).
