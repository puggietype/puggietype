puggietype Security Policy

We take the security of puggietype seriously. If you have found a vulnerability, please let us know so we can fix it.

How to report a vulnerability

Report vulnerabilities privately via a GitHub security advisory . Please include:

  • A description of the vulnerability
  • Steps to reproduce or a proof of concept
  • The potential impact

Please do not disclose the issue publicly until a fix has been released. For non-security bugs, open a regular GitHub issue .

Scope

In scope: the puggietype source code and website, including the multiplayer game server. Out of scope: third-party services, social engineering, and denial of service attacks.

Guidelines

Do not engage in activities that might cause a denial of service, put significant strain on resources, or affect other players.
