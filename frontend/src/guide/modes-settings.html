Test modes and key settings

PuggieType opens on a 30-second English test, but the bar above the words and the settings page let you change almost everything about it. This guide explains each mode and the settings that matter most.

Test modes

Time

Type as many words as you can before the clock runs out: 15, 30, 60 or 120 seconds, or a custom length. Time mode is the best way to compare results from day to day because every test lasts exactly as long. Short tests (15 seconds) reward bursts of speed; 60 and 120 seconds test stamina and accuracy under fatigue. Time is the default mode, set to 30 seconds.

Words

Type a fixed number of words, 10, 25, 50 or 100, and the timer stops when you finish the last one. Words mode is useful for drills: a 25-word test takes well under a minute and makes it easy to repeat a short exercise many times in a row.

Quote

Type a real passage from a book, film or speech instead of random words. You can pick short, medium, long or very long ("thicc") quotes, search for a specific one, or keep a list of favorites. Quotes contain natural punctuation, capital letters and longer words, so they are closer to everyday writing than the word lists. Expect a lower speed than in time mode; that is normal.

Zen

There are no target words in zen mode. You type whatever you like and the test ends when you press shift + enter. It is good for warming up or for typing freely while the pug keeps you company. Since there is no target text, there are no mistakes to count.

Custom

Paste or write your own text. You can repeat it as written, pick words from it at random, or shuffle it, and you can end the test after a number of words, a number of seconds, or a number of sections. Custom mode is the most useful mode for targeted practice: put in the words you keep getting wrong, a passage from your own work, or code you need to type quickly.

Punctuation and numbers

In time and words mode, two toggles add punctuation (commas, full stops, quotation marks, capital letters at the start of sentences) and numbers to the word list. Both are off by default. Turning them on makes the test harder and more realistic, and is the quickest way to find out how much the symbol keys slow you down.

Language

The word list can be changed to hundreds of languages and word sets, including larger English lists with less common words. Click the language name above the words, or search for it in the command line.

Settings that change how strict the test is

SettingWhat it does
difficulty normal lets you finish no matter what. expert fails the test as soon as you submit a word with a mistake. master fails it on a single wrong key, so only 100% accuracy passes.
stop on error letter refuses to accept the next key until you type the right one. word lets you keep typing but won't move to the next word until the current one is fixed.
confidence mode on stops you going back to previous words. max disables backspace completely. It trains you to commit to each keypress.
freedom mode Lets you go back and delete any word, even one you typed correctly. Normally you can only go back to a word with a mistake in it.
min speed / min accuracy Fails the test if your speed or accuracy drops below a number you set (for example 90%). Handy as a guardrail during practice.
blind mode Hides your mistakes while you type, so you can't react to them. Your result still counts them.
strict space Treats a space at the start of a word as a typed character instead of ignoring it.
lazy mode Lets you type accented and special letters as their plain equivalents, for example "e" for "é".

Some of these settings switch each other off. For example, turning on confidence mode turns off freedom mode and stop on error, because they contradict each other. During multiplayer races, difficulty, stop on error, minimum speed and accuracy, lazy mode and funboxes are switched off so every racer plays by the same rules.

Settings that help you practice

  • pace caret shows a second caret that moves at a steady speed. Set it to a custom speed a little above your average, or to your last result, and try to stay ahead of it.
  • indicate typos shows what you actually typed below or instead of the correct letters, so you can see your usual mistakes.
  • live speed and accuracy show your current numbers while you type. Many people find them distracting; try both.
  • keymap draws a keyboard on screen and can highlight the next key, which helps when you are learning to type without looking.
  • layout emulates a different keyboard layout such as Dvorak or Colemak on a standard keyboard, so you can try one without changing your system settings.

Appearance and comfort

  • theme: over a hundred color themes. The default is puggie dark, with puggie light as its light counterpart.
  • font family and font size: the default font is JetBrains Mono, a monospace font where every letter has the same width.
  • caret style and smooth caret: change the cursor's shape and how smoothly it glides between letters.
  • tape mode: shows a single line that scrolls sideways, instead of a block of lines.
  • pug: shows or hides the pug that types along with you.
  • sound: optional click sounds and an error sound.

While you type, the header, footer and test options fade out so only the words are left. Move the mouse to bring them back.

Shortcuts

  • tab then enter restarts the test. With the quick restart setting you can make tab, esc or enter restart in one press.
  • esc or ctrl + shift + p opens the command line, where you can search for and change any setting by name without leaving the keyboard.
  • On the result screen, the buttons under your result let you repeat the same test with the same words, or practice the words you missed.

Where your settings are kept

Your settings are saved in your browser, so they stay the same next time you visit on the same device. Clearing your browser data resets them. There is no account to sync them between devices, but you can export your settings from the settings page and import them elsewhere.
