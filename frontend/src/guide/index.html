Typing guides

These pages explain how to learn and practice typing on PuggieType, and how the test turns keypresses into the numbers on the result screen.

Each guide stands on its own. If you are new to touch typing, start with the week-by-week plan and the finger placement page. If you already type without looking, the practice plan and the accuracy guide are the ones that cover what to do once easy gains stop. The scoring pages show the exact formulas, so you can check a result yourself.

Open the typing test whenever you want to try something from a guide. Common questions that are not covered here are on the FAQ.
