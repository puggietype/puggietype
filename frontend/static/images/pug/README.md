# pug mode frames

The typing pug (config key `monkey`, shown as "pug") is drawn from the SVGs in
this folder. They are fetched by filename and inlined, so swapping a file here
changes the pug with no code change.

| file | shown when |
| --- | --- |
| `pug-idle.svg` | no paws down |
| `pug-blink.svg` | idle, randomly every 3–6 s for ~140 ms |
| `pug-left-paw-down.svg` | left hand key held |
| `pug-right-paw-down.svg` | right hand key held |
| `pug-both-down.svg` | both hands down |
| `pug-left-paw-half.svg` | ~45 ms between idle and left paw down/up |
| `pug-right-paw-half.svg` | ~45 ms between idle and right paw down/up |
| `pug-winner.svg`, `pug-winner-small.svg` | not used by pug mode yet (results/races) |

Which hand a key uses comes from `keycodeToKeyboardSide` (middle keys
alternate), see `src/ts/states/monkey.ts`. The mapping lives in
`src/ts/components/pages/test/pug-frames.ts`.

## Rules for replacement frames

- Same canvas (`viewBox="0 0 512 512"`) and registration for every frame, so
  swapping frames never jitters.
- Colour only via theme variables so every theme can tint the pug:
  `currentColor` (= `--pug-ink`) for outlines, and `var(--pug-fill, …)`,
  `var(--pug-paw, …)`, `var(--pug-mask, …)`, `var(--pug-bean, …)`,
  `var(--pug-key, …)`, `var(--pug-blush, …)` for fills. Always include a fallback colour.
  puggie themes set these in `static/themes/<theme>.css`. All other themes
  (and custom themes) get the brand's monochrome pug: `<html data-pug="mono">`
  (white fill/paws, mask + beans in ink, no blush, from
  `src/styles/pug-mono.scss`), with the pressed key in `--main-color`.
- No scripts or event handlers (they are stripped). Ids are prefixed per frame
  automatically, so `url(#id)` references are fine.

Code loads the `.svg` files by filename at runtime (nothing is bundled), so a
frame is swapped by replacing its file. The brand kit's inline-svg bundle
(`pug-frames.js`) is deliberately not shipped.

To pull new art: `pnpm sync-pug` (frames only) or `pnpm sync-pug --all`
(also favicons, logos and theme tokens), run in `frontend/` with `BRAND_DIR`
set to the brand kit checkout (required).

Source art: `brand/mascot/svg/` (original puggietype work, generated by
`brand/src/build.py`).
